# RUN: llvm-mc --disassemble -triple=alpha-unknown-linux-gnu %s | FileCheck %s

# The memory-format branches and the plain branch have far more encodings than
# code generation emits: any link register, and any branch-prediction hint --
# which is what R_ALPHA_HINT writes into a call.  Only the shapes with those
# fields fixed carry patterns, so decoding only those left every relaxed call,
# every PLT entry and the JITLink stub's own `br $27, .+4' unreadable.
#
# jsr and jmp name a predicted target, so their operand is a byte displacement
# the assembler divides by four; ret and jsr_coroutine take their field as
# written.  Each line below reassembles to the word it came from.

# CHECK: jsr $26, ($27), 40
0x0a 0x40 0x5b 0x6b
# CHECK: jsr $26, ($27)
0x00 0x40 0x5b 0x6b
# CHECK: jmp $31, ($27), 0
0x00 0x00 0xfb 0x6b
# CHECK: jmp $31, ($27), 40
0x0a 0x00 0xfb 0x6b
# CHECK: jmp $26, ($27), 0
0x00 0x00 0x5b 0x6b
# CHECK: ret
0x01 0x80 0xfa 0x6b
# CHECK: ret $31, ($27), 1
0x01 0x80 0xfb 0x6b
# CHECK: ret $31, ($26), 0
0x00 0x80 0xfa 0x6b
# CHECK: ret $26, ($26), 0
0x00 0x80 0x5a 0x6b
# CHECK: jsr_coroutine $26, ($27), 0
0x00 0xc0 0x5b 0x6b
# CHECK: br $31, 0
0x00 0x00 0xe0 0xc3
# The first word of the JITLink stub, br $27, .+4.
# CHECK: br $27, 0
0x00 0x00 0x60 0xc3
# CHECK: bsr $27, 0
0x00 0x00 0x60 0xd3
